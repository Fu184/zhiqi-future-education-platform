# 智启未来科技教育云平台 · 前端原型

基于 Vue 3、Vite 和 Vue Router 搭建的科技教育平台前端。首页及登录页使用项目中的 `DSC_4070.jpg` 作为临时背景图。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开终端给出的本地地址（默认 `http://localhost:5173/`）。生产构建运行 `npm run build`。

## 当前页面与交互

- 官网门户、平台介绍、联系入口
- 新闻资讯：分类、搜索、详情；管理台可新增和删除演示新闻
- 用户与学校体系：登录演示、学校与机构介绍、角色管理入口
- 教学中心：课程筛选、详情、章节、收藏、加入学习
- 学习任务：列表、状态筛选、完成状态切换
- 创作中心：Scratch 风格积木工作区、Python 代码编辑区、三维设计入口、保存演示作品
- AI 助手：本地规则回复的对话界面
- 商品/订单/支付：课程商品列表与选课清单界面
- 后台管理：新闻、任务、作品的本地新增和删除，以及其他管理入口

演示数据保存在浏览器 `localStorage`。登录仅使用昵称进行本地体验；没有连接优必选账号系统，也没有将参考站点账号密码写入项目。课程、学校、支付、文件上传、Python 运行和 AI 模型等正式服务还需要后端与第三方接口接入。

设计参考：用户提供的功能大纲与优必选 AI 智慧教育平台网址。当前界面是独立实现的前端原型。
